# Periodic Report Template

This template repository has been designed to facilitate collaboration between students and supervisors, providing a way to track project progress over time.

## Purpose

This template helps students and supervisors:

- keep periodic reporting consistent
- review progress through the GitHub interface for supervisors
- maintain a clean timeline of project updates

---
## Use Instructions 
The typical workflow is detailed below for students and supervisors. Please also refer to the examples in the directory `weekly-reports-examples`. 

### Student workflow
For students, the workflow mainly involves **creating and maintaining the repository**. Once the repository has been properly set up (using the present template), students add weekly reports as the project progresses, pushing those updates to GitHub so their supervisor can review them.

The idea is that students manage the technical setup. They create the repository and add weekly updates. The supervisor will then review these updates and provide feedback. 

Instructions for students can be found in the `student-detailed-TODO.html` file, which should be downloaded and viewed in a web browser. Please **follow these instructions carefully** to ensure the repository is set up and used properly.


### Supervisor workflow
For supervisors, the workflow mostly involves **weekly reviews and feedback**. In simple terms, once a student has set up a repository correctly and started adding weekly reports, the supervisor checks these reports on GitHub, provides feedback or guidance, and monitors the student’s progress over time.

The idea is that a supervisors do not manage the technical setup. Instead, they wait until the repository is ready, after which they review the weekly updates, provide feedback on the student's work and offer guidance on future steps. 

Instructions for supervisors can be found in the `supervisor-quick-guide.md` file, which is easy to view in the GitHub interface  — just click on the file name.
