## About This Repository

This repository contains the periodic reports for the above project.

The file `week-01.md` is the first report file. 
The subsequent report files are named according to the week they cover, e.g., `week-02.md`, `week-03.md`, and so on.

## Supervisor workflow
For supervisors, the workflow mostly involves **weekly reviews and feedback**. In simple terms, once a student has set up a repository correctly and started adding weekly reports, the supervisor checks these reports on GitHub, provides feedback or guidance, and monitors the student’s progress over time.

The idea is that a supervisors do not manage the technical setup. Instead, they wait until the repository is ready, after which they review the weekly updates, provide feedback on the student's work and offer guidance on future steps. 

Instructions for supervisors can be found in the `supervisor-quick-guide.md` file, which is easy to view in the GitHub interface  — just click on the file name.
